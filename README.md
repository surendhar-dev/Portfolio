# Personal Landing Page

A responsive personal developer portfolio built with HTML5, CSS3, and vanilla JavaScript.

## Project Structure

```text
portfolio/
│
├── index.html
├── style.css
└── script.js

```

## Features

* Responsive personal portfolio
* Dark / Light mode
* Typing animation
* Project filtering
* About section
* Project showcase
* Contact form

## How to Run

Open `index.html` in your browser.
